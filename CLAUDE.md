# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

This is a self-paced electronics learning project, not a software codebase. The user is learning circuit theory and design with hands-on experimentation. Their background: ESP32 experience, hands-on building, but gaps in theoretical calculations (resistor networks, capacitor selection, transistor biasing, op-amps, power supplies).

## Key Files

- `curriculum.md` - Four-phase learning path (DC fundamentals → reactive components → semiconductors → building blocks) with PEFI chapter references
- `resources.md` - Curated links to simulators, calculators, learning videos, and reference sites
- `diary/` - Session notes documenting what was learned
- `projects/` - Practical circuit builds
- `notes/` - Topic summaries
- `reference/` - Formula sheets

## Primary Reference Book

"Practical Electronics for Inventors" (PEFI) - The user owns this book. Reference specific chapters when explaining topics.

## How to Help

- Generate practice problems for specific topics (Ohm's law, voltage dividers, RC circuits, etc.)
- Explain concepts and check calculations
- Help troubleshoot measurement vs. calculation discrepancies
- Design circuits and calculate component values
- Create reference/formula sheets for completed topics
