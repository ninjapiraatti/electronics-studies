## Circuit Simulators

### Browser-Based (No Install)

- **Falstad Circuit Simulator** - https://falstad.com/circuit/
  - Instant visual feedback, great for learning
  - See current flow, voltage levels in real-time
  - Good for RC circuits, filters, transistor basics

- **CircuitJS** - https://www.falstad.com/circuit/circuitjs.html
  - Same as above, newer version

- **Tinkercad Circuits** - https://www.tinkercad.com/circuits
  - Arduino simulation included
  - Good for beginners, limited component selection

- **EveryCircuit** - https://everycircuit.com/
  - Clean interface, animated current flow
  - Free web version has limitations

### Desktop Applications

- **LTspice** - https://www.analog.com/ltspice
  - Industry standard, free, powerful
  - Steeper learning curve but worth it
  - Excellent for analog simulation, SPICE accuracy

- **KiCad** - https://www.kicad.org/
  - Full PCB design suite (schematic + layout)
  - Free and open source
  - Learn when you're ready to make PCBs

- **Qucs-S** - https://ra3xdh.github.io/
  - Open source SPICE simulator
  - More beginner-friendly than LTspice

## Recommended Starter Equipment

You mentioned you have equipment. For reference, the essentials:

- **Multimeter** - Measure voltage, current, resistance, continuity
- **Breadboard** - Prototyping without soldering
- **Jumper wires** - Various lengths
- **Power supply** - Adjustable bench supply ideal, USB power works for low current
- **Resistor kit** - Assortment of common values (E12 or E24 series)
- **Capacitor kit** - Ceramic (100nF essential), electrolytic assortment
- **Transistor assortment** - 2N2222/2N3904 (NPN), 2N3906 (PNP), IRLZ44N or similar logic-level MOSFET
- **Diodes** - 1N4148 (signal), 1N4007 (rectifier), various Zeners
- **Op-amps** - LM358, TL072, or similar jellybean op-amps
- **Regulators** - 7805, 7812, LM317, AMS1117-3.3

## Note on Using Resources

Don't try to consume everything. Use this document as a reference when you need:
- A simulator to visualize a concept
- A calculator to verify your math
- A video explanation of something confusing
- A datasheet for a component

Your primary path is the curriculum + PEFI book + hands-on building.
