# Electronics Studies

Self-paced electronics learning project. Moving from hands-on experimentation to understanding the theory behind circuit design.

## Structure

```
├── curriculum.md      # Learning path with topics and exercises
├── resources.md       # Tools, simulators, learning materials, links
├── diary/             # Session notes, learnings, questions
├── projects/          # Practical builds combining multiple concepts
├── notes/             # Topic summaries in my own words
└── reference/         # Quick reference sheets, formulas
```

## Learning Approach

1. Read theory (PEFI book + curriculum notes)
2. Do calculations on paper
3. Build the circuit
4. Measure and compare to calculations
5. Document in diary

## Primary Reference

Practical Electronics for Inventors
